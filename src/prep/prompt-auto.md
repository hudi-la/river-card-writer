# 附加：这一档额外要整句译文

这份稿子的档位是「给译文」。除了上面那些词典条目，再多给一个 `translation` 字段。

- **`translation` 是每段一个字符串的数组，段数必须和中文段数完全一致。**
- 译文要用上你自己在上面推荐的候选词——两边不一致的话，条目就白做了。
- 译文只是**参考**。作者会看着它自己把句子敲出来，而不是粘贴它。所以宁可准确、贴合语感，不必刻意求"顺滑到可以直接用"。
- 其余所有规则不变：条目里的 `nuance`、`loses`、`why_fits` 这些字段**仍然不许出现整句英文**，句子只能待在 `translation` 里。

输出 JSON 的顶层因此多一个字段：

```
{
  "genre": ...,
  "genre_reason": ...,
  "translation": ["第一段的英文", "第二段的英文"],
  "targets": [ ... ]
}
```
